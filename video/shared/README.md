# Shared video assets

Cross-iteration material for the Kelp films.

- `theme.json` — brand colour and type tokens used by every iteration.
- Iteration 1 (`../hyperframes/`) is self-contained: its fonts, music and SFX
  live in `hyperframes/assets/` so the project renders offline and can be
  opened on its own. Future iterations can copy from there or link tokens
  from `theme.json`; no shared binary asset is duplicated here yet.
