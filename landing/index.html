Privacy, in draft.

This standalone landing page is a product preview, not the live Kelp service. Dashboard links use app.kelp.local, a placeholder domain. The service privacy policy, operator details, and contact information are not yet supplied.

Prompts and example decisions stay in this page’s memory and are not sent to a server. Voice and file uploads are not connected. This page sets no cookies and uses no analytics. Dismissing the storage notice saves one preference in local storage.

Fonts load from Google Fonts and animation scripts from jsDelivr. Those providers receive standard network request information. Replace this draft with the final privacy policy before launch.
